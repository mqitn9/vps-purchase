## 下单前先确认虚拟化类型：只买 KVM

虚拟化类型比价格更重要，这一条能过滤掉大半的低价坑。KVM 是完整的硬件虚拟化：你的 VPS 有独立内核，Docker、WireGuard 这类依赖内核模块的服务都能正常跑，分给你的内存是实打实占住的，商家没法把同一份内存再卖给别人。OpenVZ 则是容器方案，所有租户共用宿主机内核：Docker 装不上，大部分 VPN 服务端跑不了，内存经常标成“可突发”，实际能不能用要看同时在线的邻居。

OpenVZ 的重灾区就是超低价套餐，因为它的超售空间大。几个信号帮你提前识别：价格明显偏离市场，比如 1–2 美元/月却标着 2核4G；预算套餐上写“无限资源”；商品页不公开 CPU 型号；社区反馈里反复出现“高峰期变慢”。撞上任何一条，直接跳过。

## 常见问题

**1GB 内存够用吗？** 跑静态网站、轻量应用、自用代理够用，Nginx 空载只占十几 MB。WordPress 建议 1GB 起，多站点或带数据库就上 2GB 以上。拿不准时记住一条：内存通常是第一个瓶颈。

**流量用超了会怎样？** 主流商家的处理方式是限速或按 GB 收费。RackNerd 促销套餐的月流量从 500GB 到 7TB，个人项目基本用不完；要跑大流量业务，先看超量条款。

**为什么同配置价格差这么多？** 主要差在虚拟化类型、vCPU 共享还是独享、存储是 NVMe 还是 SATA。NVMe 的随机读写比机械盘高一千倍以上，数据库和 Docker 场景差距明显；页面只写"SSD"不写 NVMe 的，先问清楚。

**月付还是年付？** RackNerd 年付促销的单价压得很低，长期服务直接年付，成本差好几倍；$1.99/月的月付更适合短期测试机。
